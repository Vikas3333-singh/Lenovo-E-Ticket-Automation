TicketForge

Lenovo E-Ticket Automation System for Hardware Support Management

Python · Selenium · openpyxl · Excel Automation

Engineers were manually logging into the Lenovo portal, filling forms one at a time, then copying case IDs and statuses back into Excel. For bulk hardware issues across multiple devices, this was a significant time sink and a reliable source of copy-paste errors. TicketForge eliminates the full manual cycle — from submission to monitoring — with structured Excel logging at every step.

Problem

Manual portal form-filling for every Lenovo ticket, followed by manual case ID extraction and Excel updates. Error-prone, time-consuming, and not scalable for bulk device issues.

Solution

Python + Selenium automation handles portal login, form submission, case ID capture, and status updates — driven from an Excel device list, writing all outputs back automatically.

Impact

Manual ticket creation eliminated for single and bulk cases. Zero copy-paste errors in the tracker. IT team has on-demand case visibility without touching the portal.

Key features

  • Single ticket mode — one device, one command.
  • Bulk ticket mode — reads device list from Excel, creates all tickets in sequence.
  • Auto case ID capture after portal submission, written back to Excel.
  • Status monitoring — checks open/closed/in-progress, updates tracker.
  • Error handling — flags failed submissions with reason for manual review.

Tech stack

Python 3.x Selenium WebDriver openpyxl ChromeDriver GeckoDriver Excel Tracker
