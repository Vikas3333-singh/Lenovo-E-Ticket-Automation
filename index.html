Featured Case Study

TicketForge

Lenovo E-Ticket Automation System for Hardware Support Management

Python · Selenium · openpyxl · Excel Automation

TicketForge automates Lenovo support ticketing through single-ticket and bulk-ticket modes, captures case IDs from the portal after submission, writes status updates back into Excel, and supports monitoring of open, closed, and in-progress cases.

Problem

Raising Lenovo support tickets manually required engineers to fill portal forms one by one and then copy case IDs and statuses back into Excel by hand.

Solution

The system automates portal form submission, bulk Excel-driven ticket creation, case ID capture, and ongoing case-status updates.

Impact

It eliminates repetitive form-filling, reduces copy-paste mistakes in the tracker, and improves visibility across the full support lifecycle.

Key features

  • Single ticket mode for one device issue at a time.
  • Bulk ticket mode using an Excel device list as input.
  • Automatic case ID capture after Lenovo portal submission.
  • Status tracking for open, closed, and in-progress cases.
  • Error handling for failed submissions and manual review.

Tech stack

Python 3.x Selenium WebDriver openpyxl ChromeDriver GeckoDriver Excel Tracker
