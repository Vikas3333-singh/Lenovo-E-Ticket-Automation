TicketForge — Lenovo E-Ticketing Engine

Automated hardware warranty support ticketing and Excel tracking system.

View on GitHub

Support engineers historically had to manually log into the Lenovo enterprise portal, fill out 15+ form fields per broken hardware unit, and copy case IDs back into tracking spreadsheets. TicketForge automates the full lifecycle—from batch dispatching to status polling—saving hours every week with zero human copy-paste errors.

The Problem

Manual portal submission and disjointed Excel tracking created bottlenecks for bulk warranty repairs.

The Solution

Headless browser automation via Selenium, reading device queues and writing statuses automatically.

The Outcome

100% automated case submission. Zero tracking errors, complete visibility for the IT team.

  • Dual Execution Modes: Single-device rapid command or full bulk queue execution via Excel.
  • Dynamic Case ID Extraction: Automatically captures Lenovo ticket numbers and timestamps.
  • Automated Status Sync: Periodically queries open/in-progress/closed tickets and updates dashboards.
  • Robust Error Handling: Gracefully retries portal timeouts and flags edge cases for manual review.
